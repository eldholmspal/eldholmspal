Professional static website for **eldholmspal** using a light green and red visual identity.

- Custom logo and favicon
- Premium materials catalog
- Sample pricing
- Services
- Selected projects
- Process section
- Testimonial
- FAQ

**Settings → Pages → Deploy from branch → main / root**

`https://eldholmspal.github.io/`
